# Simple Web Calculator

This is a basic calculator application built with HTML, CSS, and JavaScript.

## Features

- Addition, subtraction, multiplication, and division.
- Clear button to reset.
- Decimal point input.
- Responsive design (basic).
- Error handling for division by zero.

## How to Run

1. Clone this repository or download the files (`index.html`, `style.css`, `script.js`).
2. Open the `index.html` file in your web browser.

No special build steps or dependencies are required.
